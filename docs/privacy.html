개인정보처리방침

업무·일정 · 2026년 11월 17일 시행

업무·일정(이하 ‘앱’)은 사용자가 자신의 구글 캘린더 일정과 Google Tasks 할 일을 한 화면에서 보고 고칠 수 있도록 만든 개인용 웹앱입니다.

1. 접근하는 정보

  • 구글 캘린더: 캘린더 목록과 일정 보기, 일정 만들기·고치기·지우기
  • Google Tasks: 할 일 목록과 할 일(하위 할 일, 메모 포함) 보기·만들기·고치기·지우기

앱은 사용자가 구글 로그인 화면에서 허용한 범위 안에서만 이 정보에 접근합니다. 비밀번호는 구글 화면에서만 입력되며 앱은 보거나 저장하지 않습니다.

2. 정보가 오가는 곳

모든 데이터는 사용자의 브라우저와 구글 API 사이에서 직접 오갑니다. 앱은 별도 서버를 운영하지 않으며, 데이터를 다른 곳으로 보내거나 저장하지 않습니다. 광고나 사용 분석 도구도 쓰지 않습니다.

3. 기기에 남는 정보

화면을 빨리 띄우기 위해 마지막으로 받은 일정·할 일과, 구글이 발급한 1시간짜리 접근 토큰을 사용자의 브라우저 저장소에만 보관합니다. 앱의 ‘연결 끊기’를 누르면 이 정보가 지워집니다.

4. 제3자 제공

앱은 구글에서 받은 정보를 누구에게도 제공하거나 판매하지 않습니다.

5. Google API 서비스 사용자 데이터 정책

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 권한 취소

언제든지 구글 계정 → 보안 → 타사 앱 및 서비스에서 ‘업무·일정’의 접근 권한을 삭제할 수 있습니다.
