# 업무·일정 — 구글 캘린더 + Google Tasks 한 화면

갤럭시 폴드 5에서 **구글 캘린더 일정**과 **Google Tasks 할 일**을 한 화면에서 보고 고치는 개인용 앱입니다.
폰에 **앱으로 설치**할 수 있고(PWA), 모든 기록은 구글에 바로 저장됩니다.
구글 캘린더 앱, Tasks 앱, Gmail 옆 패널에서 고친 내용도 그대로 보입니다.

- 앱 주소: <https://moontur.github.io/schedule/>

| 화면 | 접었을 때 | 펼쳤을 때 |
|---|---|---|
| 오늘 | 오늘 일정 + 할 일(지난 기한 / 오늘 / 앞으로 할 일 — 2주 안 마감, 그 아래 날짜 없는 할 일), 빠른 추가 | 일정과 할 일을 두 칸으로 |
| 할 일 | 목록 → 누르면 상세 (폰 뒤로 가기로 목록) | 왼쪽 목록, 오른쪽 상세(하위 할 일, 날짜별 메모) |
| 캘린더 | 달력 아래 그날 일정·할 일 | 왼쪽 달력, 오른쪽 그날 — 각 칸의 **크게 보기**로 한쪽만 꽉 차게, **나눠 보기**로 되돌림 (고른 보기 기억) |

## 어디에 저장되나

| 앱에서 | 구글에서 |
|---|---|
| 일정 | 구글 캘린더 (구글 캘린더에서 체크해 둔 캘린더만 보임) |
| 할 일, 마감일, 완료 | Google Tasks 기본 목록 (다른 목록도 고를 수 있음) |
| 하위 할 일 (체크리스트) | Tasks의 하위 할 일 |
| 메모 | Tasks의 메모 칸. `[2026-11-17] 내용` 형식으로 최신 메모가 위에 쌓임 |

이 기기에는 화면을 빨리 띄우기 위한 마지막 데이터와 구글이 준 1시간짜리 토큰만 남깁니다.

---

## 폰에 설치하기

1. 폰 크롬에서 <https://moontur.github.io/schedule/> 를 엽니다.
2. **구글 계정 연결**을 누르고 계정을 고릅니다.
   - 처음에는 「Google에서 확인하지 않은 앱」 안내가 나옵니다. 직접 만든 앱이라 그렇습니다. **고급 → 업무·일정(으)로 이동 → 계속**을 누르세요.
   - 캘린더(일정 보기·쓰기)와 Tasks(할 일 보기·쓰기) 권한을 허용합니다.
3. 크롬 메뉴 **⋮ → 앱 설치**(또는 홈 화면에 추가 → 설치)를 누릅니다. 앱 목록에 ‘업무·일정’ 아이콘이 생기고, 주소창 없이 열립니다.

연결은 한 번만 하면 됩니다. 토큰(1시간)이 끝나면 앱이 화면 없이 조용히 새로 받습니다.
연결을 끊으려면 오른쪽 위 동기화 표시를 눌러 **연결 끊기**를 누르거나, 구글 계정 → 보안 → 연결된 앱에서 ‘업무·일정’을 삭제하세요.

## 구조

```
docs/                 ← 실제 앱 (GitHub Pages가 이 폴더를 보여 줌)
  index.html          뼈대
  styles.css          디자인 (시안 4)
  logic.js            날짜·메모·할 일 묶기 (순수 함수)
  api.js              구글 캘린더·Tasks REST 호출
  auth.js             구글 로그인 (OAuth 2.0 리다이렉트, 조용한 재연결)
  app.js              화면 동작
  config.js           구글 OAuth 클라이언트 ID
  manifest.webmanifest, sw.js, icons/   설치·오프라인
dev/                  ← 컴퓨터에서 시험하는 도구 (가짜 구글 API)
```

## 고친 뒤 반영하기

`main` 브랜치에 올리면(push) GitHub Pages가 1~2분 안에 새 버전을 배포합니다.
폰 앱은 다음에 열 때 새 버전을 받습니다(서비스 워커가 인터넷이 되면 항상 새 파일을 받음).

## 컴퓨터에서 시험하기

Node.js와 크롬만 있으면 됩니다. 추가 설치는 없습니다.

```bash
npm test              # 자동 테스트 (날짜·메모 규칙, 구글 API 호출 흐름)
npm run preview       # dev/preview.html 생성 → 크롬으로 열면 가짜 데이터로 앱을 눌러 볼 수 있음
                      #   dev/preview.html?noauth 는 처음 쓰는 사람(연결 화면)으로 시작
npm run shots         # 폴드 5 접은/펼친 크기로 캡처하고 버튼 동작 확인 (dev/shots/)
node dev/make-icons.mjs   # 앱 아이콘 다시 만들기
```

## Google Cloud 설정 (한 번만, 참고용)

- 프로젝트에서 **Google Calendar API**, **Google Tasks API** 사용 설정
- OAuth 동의 화면: 외부(External), 게시 상태 ‘프로덕션’ (테스트 상태면 7일마다 다시 허용해야 함)
- OAuth 클라이언트: 웹 애플리케이션
  - 승인된 JavaScript 원본: `https://moontur.github.io`
  - 승인된 리디렉션 URI: `https://moontur.github.io/schedule/`
- 만든 클라이언트 ID를 `docs/config.js`에 넣음 (비밀 값 아님)
